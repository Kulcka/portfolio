# Демо-лендинги на HTML/CSS/JS

Пять одностраничных сайтов для вымышленных компаний — примеры к услуге «Одностраничный лендинг
на HTML/CSS/JS». **Компании вымышлены**, цены, адреса и телефоны — примеры (`+7 (000) 000-00-00`,
`example.com`); блоки отзывов помечены на странице как образец и не выдаются за настоящие.

| Лендинг | Живое демо | Стиль и особенности |
|---|---|---|
| Стоматология «Мятная» | [открыть](https://kulcka.github.io/portfolio/landings/dental/) | светлый медицинский; прайс по вкладкам, FAQ, запись на осмотр |
| Фитнес-студия «Пульс 42» | [открыть](https://kulcka.github.io/portfolio/landings/fitness/) | тёмная тема, крупная типографика; расписание по дням, переключатель срока абонемента |
| Онлайн-курс «SQL за 30 дней» | [открыть](https://kulcka.github.io/portfolio/landings/course/) | продуктовый; программа по неделям, интерактивный пример урока, тарифы |
| Ремонт квартир «Ровный угол» | [открыть](https://kulcka.github.io/portfolio/landings/renovation/) | строительный; калькулятор стоимости, расчёт переносится в заявку |
| Кофейня «Зерно и пар» | [открыть](https://kulcka.github.io/portfolio/landings/coffee/) | редакционный, антиква; меню по вкладкам, бронь столика на дату и время |

Все пять на одной странице: <https://kulcka.github.io/portfolio/landings/>

## Что есть в каждом

- Чистый HTML, CSS и JavaScript без фреймворков и сборки; внешних шрифтов, счётчиков и
  библиотек нет — страница весит десятки килобайт и не передаёт данные посетителей третьим сторонам.
- Адаптив от 320 до 1440 px, мобильное меню (закрывается по Esc и по клику на пункт).
- Плавная прокрутка к разделам с подсветкой текущего пункта меню; при `prefers-reduced-motion`
  анимации отключаются.
- Форма заявки: проверка полей с подсказками, маска телефона, согласие на обработку ПДн,
  скрытое поле-ловушка для ботов. **В демо заявка никуда не отправляется** — показывается
  сообщение. В рабочей версии обработчик отправляет её на почту, в Telegram или в Google Таблицу
  (место в коде — `assets/base.js`, функция-обработчик `submit`).
- SEO: `title`, `description`, `canonical`, Open Graph и картинка для соцсетей (`og.png`).
  В демо стоит `noindex`, чтобы вымышленные компании не попадали в поиск — на сайте клиента убирается.
- Доступность: семантические разделы и заголовки, подписи полей, `aria`-атрибуты у меню и вкладок,
  управление с клавиатуры, контраст текста не ниже 4,5 : 1.

## Структура

```
landings/
  assets/base.css    общая основа: сетка, шапка, кнопки, формы, вкладки, FAQ
  assets/base.js     меню, плавная навигация, появление блоков, маска телефона, форма
  assets/tabs.js     доступные вкладки (WAI-ARIA)
  <ниша>/index.html  страница
  <ниша>/styles.css  цвета, шрифты и оформление ниши (переменные CSS в :root)
  <ниша>/script.js   логика ниши: калькулятор, переключатель цен, дата брони
  <ниша>/og.png      картинка для соцсетей 1200×630
  _shots/            скриншоты всей страницы на 375 и 1280 px
```

Запуск — открыть `index.html` в браузере или раздать папку любым статическим сервером
(`python -m http.server`). Встраивание в Tilda/WordPress — блоком HTML-кода со стилями и скриптами.

## Изображения

Вся графика нарисована кодом — встроенные SVG и CSS; чужих фото, иконок и логотипов нет.
Скриншоты, картинки `og.png` и обложки сняты с этих же страниц в headless Edge.

## Как проверено

- Ширины 320, 375, 768, 1024, 1280, 1440 px — нет горизонтальной прокрутки.
- Консоль браузера — без ошибок и предупреждений.
- Форма: пустая отправка подсвечивает обязательные поля, заполненная — показывает сообщение.
- Автопроверки: у картинок есть `alt`, у полей — подписи, нет дублей `id` и битых якорей,
  один `h1`, заголовки без пропуска уровней, контраст текста ≥ 4,5 : 1 (крупного — ≥ 3 : 1).
- Разметка проверена W3C Nu Html Checker.
