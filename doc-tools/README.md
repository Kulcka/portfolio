# Обработка документов и таблиц

PDF → Excel/Word, чистка и объединение таблиц, массовое заполнение шаблонов Word, пакетная конвертация.

Результат — готовые файлы Excel, Word, PDF, CSV и отчёт к каждому: что сделано, что не распозналось
и что стоит проверить глазами. Если что-то не распозналось, это видно в отчёте и подсвечено в файле.

> Все файлы в `examples/` — демонстрационные: компания, люди, телефоны, ИНН и суммы вымышлены.

## Что умею

| Задача | Вы присылаете | Вы получаете |
|---|---|---|
| **Таблицы из PDF в Excel** (`pdf2xlsx`) | прайс, выписку, спецификацию, отчёт в PDF | Excel, где числа и даты стали числами и датами (формулы и фильтры работают), таблица, разорванная между страницами, собрана в одну, строки-разделы («Крепёж», «Инструмент») вынесены в колонку |
| **Текст из PDF в Word или TXT** (`pdf2docx`, `pdftext`) | договор, положение, инструкцию в PDF | редактируемый Word: заголовки как заголовки, абзацы целиком (без переносов строк посреди фразы), списки, таблицы; колонтитулы и номера страниц убраны |
| **Объединение таблиц** (`merge`) | много Excel/CSV из разных отделов и систем, у каждого свои названия колонок | одна таблица: «Тел.», «Номер телефона» и «Телефон» сведены в одну колонку, у каждой строки указан файл и номер строки, откуда она взята |
| **Чистка таблицы** (`clean`) | выгрузку из CRM, базу клиентов, список заявок | телефоны в одном формате `+7 (900) 000-12-34`, ИНН с проверкой контрольных цифр, даты и суммы стали датами и числами, ФИО с заглавной, дубли удалены (точные) или помечены (похожие, с опечатками); листы «До» и «Результат», журнал каждого изменения |
| **Документы по шаблону** (`docx-fill`) | шаблон письма/договора/акта в Word + список в Excel | по документу Word (и PDF) на каждую строку: ФИО, реквизиты, даты, суммы, **сумма прописью**, инициалы подставлены; имена файлов — как скажете |
| **Конвертация пачкой** (`convert`) | папку файлов | XLSX ↔ CSV ↔ JSON, Word (DOCX/DOC/RTF) → PDF; CSV сразу правильно открывается в русском Excel |

### Пример «до/после» (из `examples/`)

- **Прайс на 3 страницах** (`input/прайс_СеверСнаб.pdf`) → `output/1_pdf2xlsx/прайс_СеверСнаб.xlsx`:
  48 позиций одной таблицей, хотя в PDF она на двух страницах с повтором шапки; цены — числа;
  «по запросу» и «под заказ» оставлены текстом и подсвечены; скидки со стр. 3 — отдельным листом.
- **Выписка без вертикальных линий** (`input/выписка_сентябрь.pdf`) → Excel, 40 операций; суммы по
  колонкам совпадают со строкой «Обороты за период» до копейки. Длинное «Назначение платежа»,
  переносящееся на две строки, остаётся в одной ячейке.
- **Три таблицы клиентов** с разными названиями колонок, заголовком над таблицей, CSV в кодировке
  Windows-1251 → `output/3_merge/` (19 строк, у каждой указан источник) → `output/4_clean/`: 16 строк,
  3 дубля удалены, 2 группы похожих строк («Смирнова Ольга» / «Смирнова Ольга Викторовна»,
  опечатка «Дмитрй») показаны на отдельном листе, 4 значения не распознаны и подсвечены красным
  (неверный ИНН, неполный телефон, e-mail без домена).
- **Шаблон письма + 5 адресатов** → 5 писем Word + 5 PDF в `output/5_docx-fill/письма/`
  с суммой прописью («Один миллион двести пятьдесят тысяч рублей 00 копеек»); про адресата без
  должности предупреждает отчёт.
- **Скан договора** (картинка без текста) → честная пометка «нужен OCR» вместо пустого файла.

## Как прислать файлы

1. **Сами файлы** — как есть, не надо ничего пересохранять. Подходят PDF, XLSX, CSV, JSON, DOCX,
   DOC, RTF. Много файлов — архивом.
2. **Что нужно на выходе** — формат (Excel, Word, CSV для загрузки в 1С/CRM) и, если есть,
   пример готового результата: хотя бы 2–3 строки так, как должно получиться.
3. **Для чистки и объединения** — какие колонки обязательны, что считать дублем (например,
   «одинаковый телефон» или «одинаковые ФИО и ИНН») и что делать с дублями: удалять или помечать.
4. **Для документов по шаблону** — шаблон Word, где на месте данных стоят названия колонок в
   двойных фигурных скобках: `{{ФИО}}`, `{{Сумма|прописью}}`, `{{Дата договора|дата}}`. Если
   шаблона со скобками нет — пришлите обычный документ и отметьте, что меняется, сделаю сам.
5. **Персональные данные.** Если в файлах ФИО, телефоны, паспортные данные — предупредите заранее.
   Для оценки задачи достаточно обезличенного фрагмента.

## Чего не делаю (или только по отдельной договорённости)

- **Сканы и фотографии документов.** Если в PDF нет текстового слоя (текст нельзя выделить мышью),
  нужно распознавание (OCR) — это отдельная работа, по согласованию. Такие страницы программа не
  пропускает молча, а помечает «нужен OCR».
- **Проверка по внешним базам.** ИНН проверяется только по контрольным цифрам, телефоны —
  по формату. Существует ли организация и чей это номер, не проверяю.
- **PDF под паролем** — пришлите без пароля.
- **Старый формат `.xls`** — нужно пересохранить в `.xlsx` (или сконвертирую через Excel по
  договорённости).
- **Рукописный текст, печати, подписи** не распознаю.

## Ограничения, о которых стоит знать

- **Таблицы из PDF.** Надёжно извлекаются таблицы с сеткой и таблицы с линиями между строками
  (как в банковских выписках). Сложная вёрстка — объединённые ячейки в середине таблицы,
  многоуровневые шапки, таблицы в несколько колонок на странице, таблицы без линий вообще —
  извлекается, но требует ручной проверки; после разбора вы получаете отчёт, где перечислено всё
  сомнительное. Для таких случаев есть ручные режимы (`--strategy`, `--pages`).
- **Текст из PDF в Word.** Структура восстанавливается по размеру и жирности шрифта и по отступам.
  Документ получается редактируемым, но вёрстку один в один (колонки, врезки, точные интервалы) это не
  повторяет: нужен редактируемый текст, а не копия макета.
- **Похожие дубли** (опечатки, неполное ФИО) по умолчанию только помечаются: решение «это один
  человек или два» остаётся за вами. Удалить автоматически — флаг `--drop-fuzzy`.
- **PDF через Word** — нужен установленный Microsoft Word (Windows).

## Для технических специалистов

### Установка (Windows, Python 3.10+)

```powershell
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\pip install -e .
.venv\Scripts\doctools -h
```

Зависимости лёгкие: pdfplumber, openpyxl, python-docx, rapidfuzz, PyYAML, fpdf2 (для демо), pywin32.
Tesseract и модели OCR не нужны.

### Команды

```powershell
# PDF -> Excel (все таблицы, по листу на таблицу + лист «Отчёт»)
doctools pdf2xlsx прайс.pdf -o прайс.xlsx
doctools pdf2xlsx выписка.pdf --pages 2-5 --source-page      # страницы и колонка «Стр. PDF»
doctools pdf2xlsx отчёт.pdf --strategy rows                   # таблица без вертикальных линий

# PDF -> Word / TXT
doctools pdf2docx договор.pdf -o договор.docx
doctools pdftext положение.pdf -o положение.txt --no-tables

# Объединение: файлы, папки, маски; словарь колонок — свой YAML
doctools merge отдел1.xlsx отдел2.xlsx заявки.csv -o все.xlsx
doctools merge "выгрузки\*.xlsx" -o все.xlsx --config мой_словарь.yaml

# Чистка
doctools clean база.xlsx -o база_чистая.xlsx --dedup-keys "ФИО,Телефон" --fuzzy-keys ФИО
doctools clean база.csv -o база.xlsx --type "Моб=телефон" --type "Код=текст" --drop-fuzzy

# Документы по шаблону (+ PDF через Word)
doctools docx-fill шаблон.docx список.xlsx -o готовые --name "Договор_{{Номер}}_{{Компания}}" --pdf

# Конвертация пачкой
doctools convert выгрузки --to csv -o csv --sep ";" --encoding cp1251     # для 1С
doctools convert база.xlsx --sheet Результат --to json -o json
doctools convert договоры --to pdf -o pdf                                    # через Word
```

У каждой команды есть справка: `doctools <команда> -h`. После каждого запуска рядом с результатом
сохраняется отчёт `<имя>_отчёт.md` (для папок: `отчёт_<команда>.md`), в Excel он дублируется листом
«Отчёт».

Коды выхода: `0` — готово; `2` — ошибка во входных данных (сообщение по-русски, что исправить);
`3` — внутренняя ошибка (запустите с `--debug` и пришлите вывод).

### Форматы в шаблонах Word

| Плейсхолдер | Что подставится |
|---|---|
| `{{Колонка}}` | значение как есть (даты — ДД.ММ.ГГГГ) |
| `{{Сумма\|деньги}}` | 1 250 000,00 |
| `{{Сумма\|прописью}}` | Один миллион двести пятьдесят тысяч рублей 00 копеек |
| `{{Дата\|дата}}` | 01.10.2025 |
| `{{Кол-во\|число}}` | 1 250 |
| `{{ФИО\|инициалы}}` | Иванова А. С. |
| `{{Поле\|заглавные}}`, `{{Поле\|строчные}}` | регистр |
| `{{№}}` (в `--name`) | номер строки |

Плейсхолдеры работают в тексте, таблицах, колонтитулах и надписях, в том числе если Word после
правок разбил их на несколько кусков. Названия колонок сравниваются без учёта регистра и «ё/е».

### Как адаптировать под новый заказ

- **Другие названия колонок** — скопировать `doctools/columns.yaml`, дописать синонимы, передать
  `--config`. Порядок ключей в YAML — порядок колонок в итоговой таблице.
- **Тип колонки определился не так** — `--type "Колонка=тип"` (телефон, ИНН, e-mail, дата, число,
  имя, текст, пропустить).
- **Что считать дублем** — `--dedup-keys`; похожие строки — `--fuzzy-keys` и `--fuzzy-threshold`.
- **Нестандартная таблица в PDF** — `--strategy lines|rows|text`, `--pages`.

### Демо и тесты

```powershell
.venv\Scripts\python.exe examples\run_demo.py            # генерирует examples\input и examples\output
.venv\Scripts\python.exe examples\run_demo.py --no-word  # без Microsoft Word
.venv\Scripts\python.exe -m pytest                       # основные тесты
.venv\Scripts\python.exe -m pytest -m word               # тесты с Microsoft Word (COM)
```

Word запускается отдельным невидимым экземпляром, открытые у вас документы он не трогает. После
работы Word закрывается; если он завис, принудительно завершается только тот процесс, который был
запущен программой.

### Структура

```
doctools/
  cli.py          единый CLI и сохранение отчётов
  pdf_tables.py   pdf2xlsx: поиск таблиц, склейка по страницам, колонки по просветам
  pdf_text.py     pdf2docx / pdftext: абзацы, заголовки, списки, колонтитулы
  merge.py        объединение и словарь колонок (columns.yaml)
  clean.py        чистка, дубли, журнал изменений
  docx_fill.py    заполнение шаблонов Word
  convert.py      пакетная конвертация
  word_com.py     Microsoft Word через COM с гарантированным закрытием
  normalize.py    числа, даты, телефоны, ИНН, сумма прописью
  tableio.py      чтение/запись XLSX, CSV, JSON; оформление Excel
  report.py       отчёт (Markdown + лист Excel)
  samples.py      генератор демо-набора (он же — фикстуры тестов)
examples/         run_demo.py, input/ (демо-входы), output/ (результаты всех команд)
tests/            pytest
```
