# Конфигуратор входной двери — картинка из слоёв и расчёт цены

Веб-калькулятор для сайта: покупатель собирает дверь по шагам, и каждый выбор меняет свой слой
картинки — полотно, фрезеровку, стекло, ручку, глазок, короб, фрамугу. Остальные слои остаются
на месте, смена идёт плавно. Цена пересчитывается сразу, рядом — состав «Ваша дверь» с ценой
каждой опции.

Всё, что видит покупатель, — группы, варианты, цены, картинки, порядок слоёв и правила
совместимости — задаётся в одном файле `config.js`. Чтобы поставить свои картинки и цены,
код трогать не нужно.

## Что умеет

| Возможность | Как устроено |
|---|---|
| Картинка из слоёв | слои — файлы одного размера с прозрачным фоном, накладываются по порядку; каждый выбор меняет только свой слой |
| Слои, зависящие от других опций | в пути картинки можно подставить выбор другой группы: `layers/coating/{size}/oak.svg` — у полуторной двери своё полотно |
| Цена | базовая цена + надбавки выбранных вариантов; итог и состав обновляются сразу |
| Совместимость | правила в конфиге: «с классической филёнкой стекло недоступно». Недоступный вариант неактивен и подписан причиной; если несовместимое уже выбрано, оно заменяется, и покупатель видит подсказку |
| «Поделиться» | выбор хранится в адресе страницы (`#size=single&coating=oak…`); по ссылке открывается та же дверь |
| «Скачать картинку» | слои склеиваются в PNG 1200 × 2000 |
| «Оставить заявку» | имя, телефон, комментарий с проверкой полей; в заявку попадают состав двери, итог и ссылка. В демо заявка показывается на экране, на сайте — уходит на почту / в Telegram / CRM |
| Телефон | картинка прилипает сверху, опции ниже, внизу — итог и кнопка заявки |
| Доступность | варианты — настоящие радиокнопки с подписями: выбор стрелками с клавиатуры, видимый фокус, описание картинки для экранных дикторов |
| Без зависимостей | чистые HTML, CSS и JS, без сборки и внешних библиотек; открывается двойным кликом по `index.html` |

## Файлы

```
index.html          страница демо
configurator.css    оформление (все правила внутри .dc — стили сайта не задеваются)
configurator.js     логика и интерфейс
config.js           группы, варианты, цены, картинки, правила — единственное, что нужно править
layers/             слои картинки (демо — SVG 600 × 1000)
thumbs/             миниатюры вариантов (60 × 90)
tests/              тесты: node --test
tools/draw-layers.js  генератор демо-слоёв (для своих картинок не нужен)
```

## Запуск и проверка

Открыть `index.html` в браузере — двойным кликом или через любой веб-сервер.

Тесты (нужен Node.js 18+, без установки пакетов):

```
node --test
```

Проверяют расчёт цены, правила совместимости, ссылку «Поделиться» (для всех 34 560 сочетаний
демо-опций), проверку конфига, проверку и состав заявки, а также что каждый файл, указанный в
`config.js`, существует и имеет размер холста. **Запускайте тесты после правки конфига или
замены картинок** — они сразу покажут опечатку в пути или цене.

## Как встроить на ваш сайт

### Вариант 1. iframe — одной строкой

Выложите папку на сайт (например, в `/door/`) и вставьте на нужную страницу:

```html
<iframe src="/door/index.html" style="width:100%;height:1100px;border:0" title="Конфигуратор двери"></iframe>
```

Подходит для любого конструктора (Tilda, WordPress, Bitrix, Wix): блок «HTML-код» / «Произвольный
код». Высоту подберите под страницу.

### Вариант 2. Прямо в страницу — 3 файла

Так конфигуратор наследует ширину страницы и не нуждается в прокрутке внутри рамки.

1. Загрузите на хостинг `configurator.css`, `configurator.js`, `config.js` и папки `layers/`,
   `thumbs/` (в Tilda — через «Файлы» или любой внешний хостинг, в WordPress — в медиатеку или
   тему, в Bitrix — в `/upload/`).
2. В `config.js` укажите, где лежат картинки:
   `assetsBase: 'https://ваш-сайт.ru/door/'`.
3. Вставьте на страницу блок HTML:

```html
<link rel="stylesheet" href="https://ваш-сайт.ru/door/configurator.css">
<div data-door-configurator></div>
<script src="https://ваш-сайт.ru/door/config.js"></script>
<script src="https://ваш-сайт.ru/door/configurator.js"></script>
```

Если картинки лежат на другом домене, чем страница, для «Скачать картинку» этот домен должен
отдавать заголовок `Access-Control-Allow-Origin` (для CDN и медиатек обычно включён).

Выбор покупателя пишется в адрес страницы (`#size=…`), чтобы работала кнопка «Поделиться». Если
это мешает якорям сайта, поставьте в конфиге `syncHash: false`.

## Как заменить картинки своими

1. **Один холст на все слои.** Все слои — одного размера, например 1200 × 2000 px, и
   нарисованы в одних координатах: полотно лежит там же, где оно будет на готовой двери. Удобно
   делать в Photoshop или Figma: один файл-макет, каждый слой — отдельная группа, экспорт каждой
   группы на всю площадь холста.
2. **PNG с прозрачным фоном** (или SVG / WebP). Непрозрачным делайте только нижний слой — фон
   или интерьер.
3. **Один вариант — один файл.** Разложите по папкам: `layers/coating/oak.png`,
   `layers/handle/gold.png` и т.д.
4. **Если слой зависит от другой опции** (у полуторной двери шире полотно, фрамуга в цвет
   короба), сделайте файлы для каждого сочетания и поставьте в путь id этой опции в фигурных
   скобках: `layers/coating/{size}/oak.png` → `single/oak.png` и `oneandhalf/oak.png`. Можно
   несколько: `layers/extras/{size}/{frame}/transom.png`.
5. **Порядок слоёв** — поле `layer` у группы: больше число — выше слой. В демо: интерьер 0,
   порог 5, фрамуга и вставки 10, короб 20, полотно 30, фрезеровка 40, стекло 50, глазок 60,
   ручка 70.
6. **У варианта нет картинки** («без стекла», «без глазка») — `image: null`.
7. **Миниатюры** (`thumb`) — картинки 2 : 3, например 120 × 180. Вместо картинки можно задать
   цвет: `swatch: '#3e2b21'`.
8. Пропишите размер холста в `canvas: { width: 1200, height: 2000 }`, удалите демо-файлы из
   `layers/` и `thumbs/` и запустите `node --test`. Тесты проверят, что каждый файл из конфига
   на месте, каждый слой (PNG или SVG) ровно по размеру холста, миниатюры — 2 : 3, и что в папках
   не осталось лишних файлов.

## Как поменять цены и опции

Всё в `config.js` — это обычный текстовый файл, редактируется в любом редакторе.

```js
basePrice: 42900,                 // цена базовой комплектации, ₽
groups: [
  {
    id: 'handle',                 // латиницей, попадает в ссылку «Поделиться»
    name: 'Ручка',                // заголовок блока
    layer: 70,                    // порядок слоя на картинке
    default: 'chrome',            // выбрано изначально
    options: [
      { id: 'chrome', name: 'Нажимная, хром', price: 0,
        image: 'layers/handle/{size}/chrome.svg', thumb: 'thumbs/handle/chrome.svg' },
      { id: 'gold', name: 'Нажимная, золото', price: 2400, note: 'PVD-покрытие', ... }
    ]
  }
]
```

- **Новая опция** — добавьте строку в `options` с уникальным `id`.
- **Новая группа** (например, «Шумоизоляция» без картинки) — добавьте объект в `groups`; если
  картинки у вариантов нет, укажите `image: null`.
- **Порядок блоков на странице** — порядок в `groups`; порядок слоёв на картинке задаёт `layer`.
- **Правила совместимости** — в `rules`:

```js
{
  when:    { milling: ['classic'] },                       // если выбрано это…
  disable: { glass: ['vertical', 'squares', 'window'] },   // …эти варианты недоступны
  reason:  'Классическая филёнка делается только глухой, без стекла'
}
```

В `when` можно указать несколько групп — правило сработает, когда совпадут все.

Если в конфиге ошибка (нет `default`, опечатка в id правила, цена строкой), конфигуратор не
запустится и покажет на странице список ошибок по-русски; тесты покажут то же самое.

## Как подключить отправку заявок

В демо `lead.endpoint` пустой — заявка только показывается. Укажите адрес обработчика на своём
сервере:

```js
lead: { endpoint: '/door-lead.php', successText: 'Спасибо! Перезвоним в течение часа.' }
```

Конфигуратор отправит `POST` с JSON:

```js
fetch('/door-lead.php', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(lead)
});
```

```json
{
  "source": "door-configurator",
  "createdAt": "2026-09-28T10:00:00.000Z",
  "customer": { "name": "Анна", "phone": "+7 900 123-45-67", "comment": "Проём 900 × 2060" },
  "door": {
    "options": [{ "group": "Покрытие полотна", "option": "МДФ белый дуб", "price": 6900 }],
    "selection": { "size": "single", "coating": "oak" },
    "basePrice": 42900, "total": 49800, "currency": "₽"
  },
  "link": "https://ваш-сайт.ru/door/#size=single&coating=oak&…"
}
```

Пример обработчика на PHP — пересылает заявку в Telegram и на почту. Токен бота хранится только
на сервере, в браузер он не попадает:

```php
<?php
$lead = json_decode(file_get_contents('php://input'), true);
if (!$lead || empty($lead['customer']['phone'])) { http_response_code(400); exit; }

$lines = ["Заявка с конфигуратора", "Имя: {$lead['customer']['name']}",
          "Телефон: {$lead['customer']['phone']}", "Комментарий: {$lead['customer']['comment']}", ""];
foreach ($lead['door']['options'] as $o) $lines[] = "{$o['group']}: {$o['option']}";
$lines[] = "Итого: " . number_format($lead['door']['total'], 0, '', ' ') . " ₽";
$lines[] = $lead['link'];
$text = implode("\n", $lines);

$token = getenv('TG_BOT_TOKEN');           // из настроек сервера
$chat  = getenv('TG_CHAT_ID');
file_get_contents("https://api.telegram.org/bot$token/sendMessage?" .
  http_build_query(['chat_id' => $chat, 'text' => $text]));
mail('sales@ваш-сайт.ru', 'Заявка: входная дверь', $text);

echo 'ok';
```

Для CRM (amoCRM, Битрикс24) обработчик делает то же самое, только вместо Telegram создаёт сделку
через API CRM. В Tilda можно обойтись без своего сервера: отправлять JSON на вебхук (например,
Albato или Make), который разнесёт заявку по нужным сервисам.

## Скачивание картинки

Работает, когда страница открыта с сайта (`https://…`) или через локальный сервер. При открытии
файла с диска браузер запрещает сохранять картинки со страницы — конфигуратор сообщит об этом.
Проверить локально: `python -m http.server` в папке проекта и открыть `http://localhost:8000`.

## Браузеры

Последние версии Chrome, Edge, Firefox, Safari (включая iOS) и Яндекс Браузера.

## Демо-картинки

Слои в `layers/` и миниатюры в `thumbs/` нарисованы скриптом `node tools/draw-layers.js`
(векторные SVG, холст 600 × 1000). Изображения и цены условные — для показа механики.
